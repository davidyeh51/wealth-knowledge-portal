## 🌟 門戶概述 (Executive Summary)

本入口網站與知識庫為「大衛人生・A4 財富管理（A4.1.5 財富課程）」專屬的**管顧級多源知識庫與簡報中心**。首發旗艦完整解構歐洲最年輕上市企業創辦人兼頂尖播客主持人**史蒂文．巴列特 (Steven Bartlett)** 著作**《快樂性感的百萬富翁》（Happy Sexy Millionaire: Unexpected Truths about Fulfilment, Love and Success）**。

門戶嚴格遵循前 BCG 顧問森秀明**「無雜訊簡報製作法：8 種邏輯版型」**與全球三大頂尖顧問公司（**McKinsey 麥肯錫、BCG 波士頓顧問、Accenture 埃森哲**）的視覺設計系統，提供全站即時關鍵字索引、20 章全精華解構、線上互動簡報檢視與原生 16:9 `.pptx` 簡報下載。

## 🧭 六大核心功能 (Key Features)

1. **入口網站與多源擴充架構 (Multi-Source Hub & Catalog)**
   - 預留未來資料擴充的標準化 JSON 介面，涵蓋《張瀟雨・個人投資課》、《李璞・給忙碌者的個人保險課》與《窮查理的普通常識》。
   - 任何新增模組均可從入口無縫導航至專屬導讀、思維模型與簡報。
2. **全局即時關鍵字搜尋引擎 (Real-time Keyword Search)**
   - 支援全站秒級檢索：章節標題、Action Title（主張結論句）、內文論證、核心觀念、投影片演講備忘錄與心智模型。
   - 內建熱門標籤：`#抵達謬誤`、`#技能疊加`、`#非對稱下注`、`#橡膠球與水晶球`、`#戰略性放棄`、`#摩擦力工程`、`#全面複利`、`#極端所有權`。
3. **《快樂性感的百萬富翁》20 章全深度萃取 (20 Chapters Distillation)**
   - 每一章拆解：① 本頁主張 (Action Title)、② 核心觀念、③ 關鍵論證與事實證據、④ 警示盲點 (Trap Warning)、⑤ 管顧落地行動 (Action)、⑥ 經典金句。
   - 支援五大維度快速篩選（破除迷思、重構驅動力、創造熱情、極限心智模型、下注人生）。
4. **無雜訊頂尖顧問簡報 (Zero-Noise Consulting PPTX)**
   - 12 頁 16:9 寬螢幕實體簡報檔案（`happy_sexy_millionaire_zero_noise.pptx`）。
   - 嚴格落實「形式對應邏輯」與「由上而下的閱讀動線（結論置頂）」。
   - 每頁內建完整的「逐頁三段式演講備忘錄」（① 本頁結論、② 補充說明、③ 下一頁轉場）。
5. **六大底層心智模型矩陣 (Cognitive Frameworks)**
   - 抵達謬誤 (Arrival Fallacy)、橡膠球與水晶球 (Rubber & Glass Balls)、技能疊加 (Skill Stacking)、非對稱賭注 (Asymmetric Bets)、行為摩擦力 (Friction Engineering)、極端所有權 (Extreme Ownership)。
6. **一鍵複製 AI 研討提示詞 (NotebookLM / Claude / Gemini Prompt)**
   - 內建管顧標準 Prompt 模板，方便用戶將全書脈絡與簡報結構直接貼入 AI 展開延伸對話。

## 🛠️ 未來資料擴充作業指引 (How to Add New Modules)

本專案採用解耦資料架構，未來若要擴充新書籍或課程：
1. **建立資料檔案**：在 `wealth-knowledge-portal/data/` 新增 `course_id.json`。
2. **產出簡報**：執行 `python generate_noisefree_pptx.py --style hybrid --json slides.json --output filename.pptx`。
3. **註冊模組節點**：在 `wealth-knowledge-portal/data/catalog.json` 的 `modules` 陣列新增節點：
   ```json
   {
     "id": "module-new-course",
     "status": "online",
     "badge": "已上線",
     "title": "課程或書籍名稱",
     "author": "作者名",
     "presentation_file": "filename.pptx",
     "tags": ["標籤1", "標籤2"]
   }
   ```
4. 前端搜尋與目錄將自動完成熱更新與連結對齊！
